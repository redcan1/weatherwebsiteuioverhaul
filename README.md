# The Nerd Map

A static website that shows live environmental data on interactive maps: weather, severe weather alerts, hurricanes, wildfires, earthquakes, air quality, natural events, the aurora, tides and the ISS.

## Running it

There is no build step. Serve the `frontend/` folder with any static file server, for example:

```
py -m http.server 8000 --directory frontend
```

Then open http://localhost:8000. Browser geolocation ("Use my current location") needs `http://localhost` or HTTPS.

## Editing pages

The HTML pages are generated by `tools/build_pages.sh` from one shared template, so the header, navigation, location panel and footer stay identical everywhere. To change a page's layout, edit the script and run it:

```
bash tools/build_pages.sh
```

It overwrites the `.html` files in `frontend/`, so don't edit those by hand. Page behaviour lives in the `.js` files, which the script doesn't touch.

## Features across every page

- **°F / °C switch** in each page heading, above the data sources (stored in `localStorage`, applied by reloading). Pages read `UNIT` / `METRIC` from `common.js`.
- **Saved places**: save the current location and switch between up to 8 places from the Location panel.
- **Shareable links**: the URL carries `lat`, `lon`, `name` and `map=lat,lon,zoom`; **Share** copies it (or opens the phone share sheet).
- **Auto-refresh**: each page re-fetches its data with `autoRefresh(task, minutes)` while the tab is visible (5 min for alerts and quakes, 10 for weather and radar, longer for slower sources).
- **Dark mode** follows the system setting, including Esri's dark gray basemap.
- **Installable app (PWA)**: `manifest.webmanifest` + `sw.js`. Site files are network-first with an offline fallback; map tiles are cache-first; API responses are kept for offline use. **Bump `VERSION` in `sw.js` when you add or rename site files.**
- **Accessibility**: skip link, labelled controls, WCAG AA colour contrast in both themes (checked with axe-core).

## Layout

| File | Purpose |
| --- | --- |
| `style.css` | Design system shared by every page: tokens, layout, panels, stats, charts, map cards |
| `common.js` | Shared helpers: icons, formatting, Esri basemaps, the location panel (city search, geolocation, saved location) |
| `charts.js` | Small dependency-free SVG line and bar charts with hover tooltips |
| `index.html` + `weather.js` | Current conditions, 24-hour outlook, 7-day forecast, humidity chart; radar and satellite (animated together) and regional humidity map layers |
| `severe.html` + `severe.js` | NWS warnings, watches and advisories, local alert text, NHC storm tracks and cones |
| `wildfires.html` + `wildfires.js` | Active US fire perimeters, largest fires, nearest fire |
| `seismic.html` + `seismic.js` | M2.5+ earthquakes from the past day or week, strongest and nearest quakes |
| `air.html` + `air.js` | US AQI, pollutant levels and a 24-hour AQI forecast |
| `events.html` + `events.js` | NASA EONET natural events worldwide, with category filters and storm tracks |
| `aurora.html` + `aurora.js` | NOAA OVATION aurora probability map, viewing chance and Kp index chart |
| `ocean.html` + `ocean.js` | Nearest NOAA tide station, upcoming tides, tide chart, waves/swell/sea temperature |
| `iss.html` + `iss.js` | Live ISS position, ground track, footprint and passes over you (computed in the browser with satellite.js) |
| `about.html` | What the site is and where every piece of data comes from |

The location a visitor picks is saved in `localStorage`, so every page opens on the same place.

## Data sources

All sources are free and need no API key. See `about.html` for details.

- **Open-Meteo**: forecast, air quality and geocoding APIs
- **RainViewer**: precipitation radar tiles (free tiles stop at zoom 7, so they're scaled up beyond that)
- **NASA GIBS**: GOES-East GeoColor satellite imagery (the newest frame is looked up via DescribeDomains)
- **National Weather Service**: alert shapes from NOAA's watch/warning map service; local alert text from api.weather.gov
- **National Hurricane Center**: storm forecast points, track and cone from NOAA's tropical map service (one `identify` request covers all 15 storm slots)
- **NASA EONET**: open natural events (storms, wildfires, volcanoes, sea ice…)
- **NOAA SWPC**: OVATION aurora forecast grid and planetary Kp index (observed + forecast)
- **NOAA Tides & Currents**: tide stations and predictions (station list cached in the browser for a week)
- **Open-Meteo Marine**: waves, swell and sea surface temperature
- **CelesTrak** (backup: wheretheiss.at): ISS orbital elements; positions and passes computed with satellite.js 5.0.0 from cdnjs
- **NIFC WFIGS**: current interagency fire perimeters
- **USGS**: FDSN earthquake event service
- **Esri ArcGIS Online**: Light Gray Canvas and World Street Map basemaps
- **Leaflet 1.9.4** (from unpkg) and the **Inter** font (from Google Fonts)

The Traffic and Crime tabs were removed. Traffic APIs (TomTom, HERE and others) and the FBI Crime Data API all require an API key.

`humidity.html` is a redirect stub: the Humidity page was merged into the Weather page, and the stub keeps old links working.
